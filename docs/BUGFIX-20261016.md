## 修復對照

| 檢查問題 | 修復 |
| --- | --- |
| 資料夾別名可繞過來源防覆寫 | ExportService／SourceFileProtection 比較 FILE_ID_INFO，匯出期間鎖定來源、提交前重查；使用 CreateNew 隨機暫存檔 |
| 安全失敗後成功仍顯示舊警告 | 預覽錯誤獨立管理，恢復成功清除對應錯誤，不再保留失敗的 StatusText |
| 預覽清掉真正的保存錯誤 | PersistenceError 獨立保存與顯示，只有較新的成功保存可清除 |
| 規則未落盤即報成功 | SaveAsync／DeleteAsync 等待保存結果；失敗保留草稿身分／恢復刪除規則，支援重試；操作中停用編輯避免重入 |
| 圖片已寫出卻誤報匯出失敗 | 圖片提交成功即為匯出成功，偏好錯誤另外顯示，不將 JPG 誤報失敗 |
| 關閉取消最後偏好寫入 | 保存不共用渲染取消 token；原生關閉等待 Flush，失敗需使用者選擇是否放棄 |
| 多個 SettingsStore 共用暫存檔 | 每次獨立暫存檔，跨程序檔案鎖序列化提交；最後完整快照提交者優先，讀取容許替換 |
| 小數逗號地區 EXIF 數值缺失 | 照片數值字串統一 InvariantCulture，並拒絕 NaN／Infinity |
| 發布先刪除上一版 | staging 建置、檢查 EXE、壓縮完成後才切換，保留 previous 備份並處理替換失敗回復 |
