## 2026-10-17：格式 8、內建八組表與鏡頭 8–100px

目前格式為 8。`BuiltInMarginPresets.Create()` 是新建／重建內建預設的唯一正式來源；`builtInRevision=1` 記錄此表。載入版本 2–7 時，只對 ID 為 default、且該組完整數值／保護值仍與舊預設相等的配置更新；任何欄位已修改就保留整組，自訂 ID 即使與舊預設同值也不更新，名稱及選取 ID 不改。原作品只有在仍是未修改的舊內建副本時才同步更新，新表以 4:3 及目前排列初始化；手動作品與字體／匯出等設定保留。已無預設的清單不重建，成功保存版本 8 後不再升級重寫。

## 2026-10-17：格式 7 與底部定位

目前格式為 7，接受 2 至 6，不因版本不同回復預設；讀取失敗沿用保存保護。`bottomSafeDistance`／`bottom` 改顯示為「下方邊距」，`cropExtraPadding`／`extra` 為「文字與左右邊界」，`photoInfoGap`／`gap` 為「照片與文字間隔」，`exposureItemGap` 為「焦距、曝光三要素間隔」。序列化鍵不改，八組配置、ID、名稱與所有數值保留。

## 決策

- 橫向與方形來源由 MVP 接受；校正後為直向的候選影像會被釋放，原作品與手動資料保持不變。
- 方向判斷一律發生在 EXIF Orientation 校正後。
- 所有 1080 基準設定在 Core 依輸出尺寸等比例縮放。
- 設定格式版本為 2。不存在或版本不同的舊設定會回到新版橫向預設，避免舊直向設定覆蓋版面。
- 影像依賴只存在於 Imaging；Core 可獨立測試。

## 後續直向版型

新增直向正式支援時，應建立獨立的方向版型設定與遷移版本，不能覆蓋目前橫向預設。新增 2:3、3:4、4:5、9:16 回歸案例後，才移除 `OrientationPolicy.PortraitUnsupportedMessage` 的匯入阻擋。

依使用者要求，移除裁切預覽選單及其 enum、事件、偏好欄位和渲染分支，預覽固定顯示完整成品；4:5／5:4 安全區幾何仍供文字保護與輔助線使用。移除獨立的回復 EXIF 原值操作，透過重新讀取資訊更新原始值。日期輸入改為可空值的 DatePicker，自動使用 EXIF 拍攝日期；日期缺值不帶入今天。
