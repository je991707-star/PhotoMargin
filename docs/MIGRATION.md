# 遷移記錄

本工作區起始狀態只有 `Agent.md`，沒有既有 Python 或 C# 程式，因此本次是依新版規格建立全新的純 C# solution，沒有刪除舊檔或建立 Python 橋接。

## 決策

- 橫向與方形來源由 MVP 接受；校正後為直向的候選影像會被釋放，原作品與手動資料保持不變。
- 方向判斷一律發生在 EXIF Orientation 校正後。
- 所有 1080 基準設定在 Core 依輸出尺寸等比例縮放。
- 設定格式版本為 2。不存在或版本不同的舊設定會回到新版橫向預設，避免舊直向設定覆蓋版面。
- 影像依賴只存在於 Imaging；Core 可獨立測試。

## 後續直向版型

新增直向正式支援時，應建立獨立的方向版型設定與遷移版本，不能覆蓋目前橫向預設。新增 2:3、3:4、4:5、9:16 回歸案例後，才移除 `OrientationPolicy.PortraitUnsupportedMessage` 的匯入阻擋。

## 2026-10-14 介面精簡

依使用者要求，移除裁切預覽選單及其 enum、事件、偏好欄位和渲染分支，預覽固定顯示完整成品；4:5／5:4 安全區幾何仍供文字保護與輔助線使用。移除獨立的回復 EXIF 原值操作，透過重新讀取資訊更新原始值。日期輸入改為可空值的 DatePicker，自動使用 EXIF 拍攝日期；日期缺值不帶入今天。
