# PhotoMargin 專案說明

文件對應版本：0.0.4。功能以目前程式碼為準；歷次驗證紀錄另見文末連結。

## 專案用途

PhotoMargin 是 Windows 攝影作品白框工具。它將已修好的 JPG／PNG 照片完整放入正方形白色畫布，加入機身、鏡頭與拍攝參數，協助攝影者產生版面一致的分享作品。

工具著重於白框排版、拍攝資訊整理與安全匯出，不是照片調色軟體，也不是 RAW 顯影器。正式執行採 C#／WinUI 3，不需要 Python 或網路服務。

## 基本操作流程

1. 解壓完整 Windows x64 發布資料夾，執行 `PhotoMargin.App.exe`；不能只複製 EXE。
2. 匯入或拖入修好的 JPG／PNG，程式校正 EXIF Orientation 並讀取拍攝資訊。
3. 在主畫面選擇預設、資訊排列與字體，必要時手動補正拍攝資訊。
4. 如 JPG／PNG 缺少資料，可在「相機資訊設定」選取同張照片的 RW2，逐欄確認補入。
5. 調整輸出尺寸、格式與品質，檢查預覽及安全提示後匯出。

輸出畫布始終為 1:1，來源照片保持完整比例、不拉伸或裁切。版本目前以橫向來源為主；方向校正後為直向的照片會提示尚未支援，保留既有作品。

## 畫面與功能

| 畫面 | 用途 |
| --- | --- |
| 主畫面 | 預覽、選擇版面、手動編輯資訊、更換照片及匯出 |
| 一般設定 | 色彩模式、資料位置、設定集備份與移轉 |
| 版面設定 | 依圖片比例與資訊排列編輯、套用及管理預設 |
| 相機資訊設定 | 純文字查看有效資訊及來源，讀取／重新讀取 RAW 或還原照片 EXIF |
| 匯出設定 | 格式、尺寸、品質、檔名、儲存策略與 metadata 選項 |

齒輪與「新增規則」使用同一個設定導覽；新增規則直接選取版面設定。設定返回鍵直接回到既有主畫面，不重新建立作品。

### 版面預設

一個預設使用穩定 ID，包含四種來源比例（16:9、5:4、4:3、3:2）乘兩種資訊排列（左右、垂直），共八組獨立配置。非標準來源比例依最接近比例選取配置，不因此裁切照片。

| 設定 | 作用 |
| --- | --- |
| 左右邊距 | 照片的最小左右留白 |
| 上方邊距 | 照片的最小上方留白 |
| 下方邊距 | 最下方可見文字到畫布底邊的距離，仍受明確啟用的裁切保護限制 |
| 照片與文字間隔 | 照片底邊到第一行可見文字的垂直距離 |
| 焦距、曝光三要素間隔 | 焦距、光圈、快門、ISO 可見項目之間的水平距離 |
| 文字與左右邊界 | 裁切可見區左右向內的文字留白，不內縮上下 |

版面數值以 1080×1080 成品的 px 為基準，按輸出尺寸等比例縮放，不隨視窗 DPI 改變。滑條與比例／排列選擇即時更新預覽；無照片時使用隨程式部署的離線示範圖與資訊，不污染正式作品。

「套用」只複製數值至作品；修改不會回寫預設，另存需使用不同名稱。「編輯」使用獨立草稿，儲存才更新原 ID，取消則丟棄修改。可刪除的預設需在編輯模式經勾選確認後永久刪除；內建預設受刪除保護。完整內建參數表見 [README](../README.md#內建預設模板參數)。

### 拍攝資訊與 RAW

資訊包含機身、鏡頭、日期時間、焦距、光圈、快門與 ISO。資料分成照片 EXIF、已確認 RAW 快照與手動覆寫，顯示實際來源；缺值不產生假參數。照片沒有拍攝日期時可使用檔案建立日期，並明確標示其並非 EXIF。

目前 RAW 選檔僅開放已實際驗證的 Panasonic GH5 `.RW2`。RAW 只作 metadata 來源，不取代 JPG／PNG，不採用其 Orientation、尺寸、色彩或縮圖改動作品。確認對話框逐欄選擇目前值或 RAW；取消／失敗不修改資料。RAW 移走後已套用快照仍可使用，重新讀取才需要原檔；更換照片會清除前張 RAW 關聯。

### 預覽、安全與輸出

預覽及正式匯出共用排版核心、文字量測與安全檢查。預設只啟用直向 4:5 裁切的左右保護；安全線僅供預覽，不寫入成品。文字太寬時可由左右分欄回退至置中堆疊，仍無法容納則提示原因並禁止匯出，不裁字或讓文字重疊。

照片輸出字體與應用程式 UI 字體分開管理。鏡頭字級可設 8–100px，預設 16px，其他資訊下限仍為 18px；不自動縮字。

實際編碼格式為 JPG、PNG、WebP。JPG／WebP 一般模式各自記住品質，PNG 與 WebP 無損模式不顯示品質百分比；JPG 品質 100 仍非無損。支援 1080、1440、2048、2160 及自訂正方形尺寸（320–8192）。各格式使用相同版面、白色畫布與 sRGB 流程。

匯出可設定目錄、檔名規則（`{name}`、`{date}`）、同名處理及完成後開啟資料夾。來源照片與關聯 RAW 一律禁止覆寫。拍攝資訊寫入預設關閉；開啟時只寫有效拍攝欄位，不複製 GPS、縮圖、舊方向或舊尺寸，ICC 色彩描述不因關閉此選項而移除。

## 資料保存與移轉

可攜版使用執行檔所在目錄的 `Data`，與工作目錄無關；不可寫或封裝部署時使用 `%LOCALAPPDATA%\PhotoMargin\Data`。每次執行固定使用一個位置，不因單次保存失敗切換資料夾。

```text
PhotoMargin/
  PhotoMargin.App.exe
  …其他執行相依檔案
  Data/
    settings.json
    presets.json
    Backups/
```

`settings.json` 保存偏好、最近選取與本機資訊快照；`presets.json` 保存預設及內建預設的修改／刪除狀態。兩檔 schemaVersion 為 1，內部偏好格式為 10，並透過交易識別、安全替換及備份處理一致性。Backups 保留最近五組；首次初始化才遷移舊資料，成功前不刪舊檔。來源照片、RAW 原檔、匯出成品及未儲存草稿不放入 Data。

一般設定可匯出單一 ZIP 設定集，僅含 `manifest.json`、可攜 `settings.json` 與 `presets.json`，不含本機絕對路徑、作品紀錄、照片、RAW、備份或草稿。匯入先驗證、確認及備份，成對取代設定與預設，保留目的電腦路徑、當前照片、RAW 與手動資訊，不自動重套版面。

色彩模式使用唯一的原生下拉入口：跟隨系統、淺色、深色。選取立即生效並保存，成品白色畫布不受 UI 主題影響。

## 程式架構

| 專案／目錄 | 責任 |
| --- | --- |
| `src/PhotoMargin.Core` | 方向政策、幾何、排版模型、版面計算與安全驗證，不依賴 WinUI |
| `src/PhotoMargin.Imaging` | 圖片解碼、EXIF／RAW metadata、色彩轉換、文字量測、合成與編碼 |
| `src/PhotoMargin.App` | XAML、MVVM、設定導覽、桌面對話框、資料保存與設定集 |
| `tests` | Core、Imaging、應用邏輯及 Windows 原生操作回歸 |
| `packaging` | Windows x64 self-contained 資料夾發布 |
| `docs` | 架構、遷移、功能及驗證紀錄 |

主要技術為 .NET 10、WinUI 3／Windows App SDK 2.5.1、CommunityToolkit.Mvvm 8.4.2、Magick.NET-Q8-x64 14.16.0、MetadataExtractor 2.9.3；版本集中於 `Directory.Packages.props`，程式版本集中於 `Directory.Build.props`。圖片函式庫包含原生相依檔案，並非單一無依賴 EXE。

Windows 開發環境的基本指令：

```powershell
dotnet restore .\PhotoMargin.sln
dotnet build .\PhotoMargin.sln -c Release
dotnet test .\PhotoMargin.sln -c Release
.\packaging\publish.ps1
```

## 範圍與驗證限制

- 尚未提供直向專用版型、批次輸出、RAW 顯影、HEIC／AVIF／TIFF 輸出、自訂品牌圖或雲端發布。
- RAW 只對已驗證的 GH5 RW2 作支援承諾，不代表所有 RAW 格式或相機均可讀。
- 拍攝資訊寫入仍有格式限制，例如 ISO 超過 65535 時會明確拒絕該 metadata 匯出，不假裝成功。
- 自動測試與原生回歸不等同所有 Windows 版本、DPI、字體、高對比、讀屏及乾淨機部署均已驗收。Program Files／MSIX 真實部署、系統主題切換及完整人工操作範圍應依交付紀錄補測。
