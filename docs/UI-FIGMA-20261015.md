## Reload 與導覽

Reload 只重新讀取目前來源的 EXIF，不重載影像、不套用版面預設。手動修改後先出現原生 ContentDialog，取消保持原值。讀取完成才提交機身、鏡頭、時間與拍攝參數；失敗保留原有資訊。讀取中或沒有照片時停用。缺少拍攝日期時帶入檔案建立日期／時間，其他缺值留白。

來源版本、資訊編輯版本、預覽版本及取消權杖共同阻止過期工作覆蓋新狀態。規則、字體、字級、尺寸、品質與安全線均不因 Reload 重設。

設定頁沿用同一個 MainViewModel。齒輪明確進入一般設定；主畫面「新增規則」明確進入版面設定。返回先回到先前設定分類，再回到原工作頁；直接從主畫面進入版面設定時，一次返回主畫面。規則集合共用並通知更新，原選取仍存在則保留。

## 原生行為與設計差異

- Windows 原生標題列與系統最小化、最大化、關閉行為保留；未增加 Mica、Acrylic、漸層或自訂 ScrollBar 模板。
- 主畫面 Grid 右內距 4 DIP，右側 StackPanel 右邊距 12 DIP，ScrollViewer 右內距 4 DIP。捲軸維持 Auto、禁止水平捲動，控制項與展開捲軸分開。
- 日期採用圖中附日曆圖示的 CalendarDatePicker，而非佔用較多寬度的三欄 DatePicker；時間為原生 TimePicker，按原生能力編輯至分鐘，成品顯示 `yyyy.MM.dd HH:mm`。
- Windows App SDK 2.5.1 的 TimePicker 內部按鈕固定最小寬度約 242 DIP；只在載入／主題變更後放寬該最小寬度，保留原本模板、飛出選擇器、焦點及鍵盤行為。整合測試檢查小視窗的時／分均完整顯示。
- NavigationView 展開時以兩個原生圖示按鈕呈現設計的並排返回／收合；收合或窄視窗改回 NavigationView 原生返回及展開控制，沒有重寫導覽模板。Alt+Left 可返回。
- 右側面板是較高完整設計，整合後垂直捲動，不縮小原生控制項。固定操作區與底部狀態列各有獨立 Grid 列；預覽畫布等比例縮放。
- 範例截圖資料由測試照片實際載入；測試照片的示範 EXIF 僅由測試程式建立，正式介面沒有硬編碼相機、日期或檔名。
